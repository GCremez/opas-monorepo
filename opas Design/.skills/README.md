## Quick reference

### Design system & tokens
- `theme-factory` — reusable theme tokens, palette variations (light/dark/high-contrast)
- `design-systems/` — 6 skills: design-token, naming-convention, color-system, typography, spacing, component-spec

### Visual & UI design
- `ui-design/` — 6 skills: visual-hierarchy, responsive-design, grid-layout, etc.
- `anthropic-frontend-design` — bans overused fonts, enforces aesthetic direction upfront
- `impeccable` — 23 commands: typeset, colorize, animate, layout, bolder, quieter
- `human-interface-guidelines` — Apple HIG patterns for iOS/macOS

### Prototyping & testing
- `openai-figma-implement-design` — translate Figma → production code
- `openai-playwright` / `composio-webapp-testing` — visual regression testing across viewports
- `openai-screenshot` — capture implementation screenshots for review
- `excalidraw-diagram-skill` — generate flowcharts, architecture, sequence diagrams

### Interaction & motion
- `interaction-design/` — 6 skills: feedback-patterns, motion-guidelines, gesture-design, etc.
- `designer-toolkit/` — prototyping-loops, handoff-qa, design-rationale

### Critique & quality
- `visual-critique/` — 5 skills: critique-color, critique-typography, critique-layout, etc.
- `accesslint` — WCAG AA/AAA contrast checks, semantic HTML, color-only-signals

### Strategy & process
- `ux-strategy/` — 6 skills: design-principles, research-synthesis, information-architecture, etc.
