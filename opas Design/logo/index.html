5. Usage guidelines

Clear space

x x x x
  • Maintain clear space equal to 1× the icon width on all sides
  • Minimum 24px for icon-only usage (still recognizable)
  • Minimum 32px for wordmark lockup

Minimum sizes

Usage Min size Format
App icon 1024×1024 PNG (no JPG)
Spotlight 80×80 PNG
Favicon 32×32 SVG / ICO
Nav bar 28×28 SVG inline
Wordmark 32px wordmark height SVG / PNG
✓ Do

Use the green accent (#92D9BB) on dark / (#1A8A7A) on light backgrounds.
Keep the mark on a circular background for app icons.
Use the lockup arrangement that fits the context (horizontal for nav, vertical for splash).
Let the dashed ring be clearly visible — don't scale below 24px.

✗ Don't

Recolor the accent to a different hue — keep it in the teal/green family.
Stretch or distort the SVG aspect ratio.
Place the mark on a busy background — the ring needs visual air.
Use the icon-only mark below 20px (switch to wordmark or remove).
