Icon guidelines

Do
  • — Use 24×24 viewBox, 1.5px stroke
  • — Keep line caps round, joins round
  • — Accompany with text label when space allows
  • — Tone to --muted when decorative, --fg or --accent when interactive
Don't
  • — Don't fill icons — stroke-only always
  • — Don't use multiple stroke weights in one icon set
  • — Don't place an icon next to every heading
  • — Don't use generic emoji as icons (✨ 🚀 🎯)
06

Usage Guidelines

How the system behaves — the unwritten rules that keep OPAS looking like one product, not six.

Rhythm

One idea per view

Every screen has one primary action, one focal headline, one accent touch at most. Don't compete with yourself.

Whitespace

Generous by default

Padding is not wasted space. Content breathes at --space-6 (32px) minimum between sections. The tightest acceptable gap is --space-4 (16px).

Typography

Serif for headlines only

Never set body copy in the display face. Never set a headline in the body face. Mono is metadata-only — never use mono for paragraphs.

Borders

Structured by edges

No shadows, no rounded corners. Separation comes from borders (1px solid --border) and whitespace. Cards are rectangles. So is everything else.

Accent budget

One touch, max two

The rust accent is a spice, not a sauce. Use it for one primary CTA + one editorial flourish (a pull quote, a stat, a tag). Never more.

Imagery

One decisive frame

When using photography, use one hero image cropped at the bottom. No collages, no multi-image grids. One image, well chosen, does more than six.

Legacy compatibility

The OPAS mobile app previously used #1B7F79 (teal) as its brand colour. If transitioning from the legacy brand, map --legacy-teal to the semantic --info token or a secondary --accent variant. Teal is not part of the Editorial Monocle palette — the rust accent replaces it. A full deprecation guide is available on request.
